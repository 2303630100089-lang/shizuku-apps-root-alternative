# AI agents

- [Mythara](https://github.com/ankurCES/project_mythara) - Open-source local-first agentic AI OS layer for Android; uses Shizuku for cosmetic system tweaks. `MIT`
- [Open-AutoGLM-Android](https://github.com/xinzezhu/Open-AutoGLM-Android) - Automates actions on your device using AutoGLM vision language model. `GPL-3.0`
- [Operit AI](https://github.com/AAswordman/Operit) - AI agent/chat app on Android with command execution support through Shizuku. `LGPL-3.0`
- [Ruto-GLM](https://github.com/iamr0s/Ruto-GLM) - Automation and multitasking framework using AutoGLM with virtual screens and multi-window support. `Apache-2.0`
