# AI agents

- **Mythara** - Open-source local-first agentic AI OS layer for Android; uses Shizuku for cosmetic system tweaks. `MIT`
- **Open-AutoGLM-Android** - Automates actions on your device using AutoGLM vision language model. `GPL-3.0`
- **Operit AI** - AI agent/chat app on Android with command execution support through Shizuku. `LGPL-3.0`
- **Ruto-GLM** - Automation and multitasking framework using AutoGLM with virtual screens and multi-window support. `Apache-2.0`
