# AI agents

- [Mythara](https://github.com/search?q=Mythara+android+shizuku&type=repositories) - Open-source local-first agentic AI OS layer for Android; uses Shizuku for cosmetic system tweaks. `MIT`
- [Open-AutoGLM-Android](https://github.com/search?q=Open-AutoGLM-Android&type=repositories) - Automates actions on your device using AutoGLM vision language model. `GPL-3.0`
- [Operit AI](https://github.com/search?q=Operit+AI+android+shizuku&type=repositories) - AI agent/chat app on Android with command execution support through Shizuku. `LGPL-3.0`
- [Ruto-GLM](https://github.com/search?q=Ruto-GLM+android&type=repositories) - Automation and multitasking framework using AutoGLM with virtual screens and multi-window support. `Apache-2.0`
